# 🎤 Voice Chatbot

A simple Arabic Voice Chatbot built using HTML, CSS, and JavaScript.  
The chatbot supports Speech-to-Text and Text-to-Speech directly in the browser without requiring any external API or backend server.

---

## 📌 Features

- 🎤 Voice Recognition (Speech-to-Text)
- 🔊 Voice Response (Text-to-Speech)
- 💬 Text Input Support
- 🌐 Runs directly in the browser
- 📱 Responsive User Interface
- ⚡ No PHP or Database Required

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Speech Synthesis API

---

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Launch **index.html** in Google Chrome or Microsoft Edge.
4. Click the microphone button and start speaking.

---

## 💡 How It Works

1. The microphone captures the user's voice.
2. The browser converts speech into text.
3. The chatbot generates a predefined response.
4. The response is spoken back using Text-to-Speech.
